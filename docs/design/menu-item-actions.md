## 1. 言葉

旧版では「この項目を保持」（次の起動に持ち越す印）と「値を固定」（ゲームが変えても戻す）が並び、紛らわしかった。この版では項目ごとの物を「固定」だけにし、「保持」は設定画面のまとまり（保持設定）と「トグルを全て保持」にだけ使う。

| 言葉 | 意味 | 画面に出る所 |
|---|---|---|
| 固定 | 外すまで今の状態を保つ。ゲームが変えても戻し、次の起動でも戻す | R のリスト（値を固定・ONで固定・固定を外す）、鍵の印、説明の状態、設定画面の「固定中の項目」、通知の題（値を固定・ONで固定・固定を外す） |
| 保持 | 次の起動に持ち越すこと。項目ごとには使わない | 設定画面の「保持設定」「トグルを全て保持」 |
| お気に入り | 一番上の一覧の先頭に集める項目 | R のリスト（お気に入りに追加・お気に入りから外す）、フォルダの行「お気に入り」、通知の題（お気に入りに追加・お気に入りから外す） |
| 次回 | 次の起動。画面の言葉では「次回」と書く（「起動」「越」は 8 画素で読みにくい） | 設定画面の説明 |
| 前回から | 起動時に前回の状態を戻した通知の題（「状態」は 8 画素で読みにくい） | 起動時の通知 |

画面の新しい言葉は全て今の字形の一覧にある字だけで書いた（字形の追加は無い）。「状態」「起動」「越」「内容」は読みにくいか一覧に無いので使わない。

## 2. R の操作のリスト

### 2.1 並べる物

行の種類ごとに、次の物だけを上から並べる（無い物は詰める）。

| 行の種類 | 固定 | お気に入り | ホットキー |
|---|---|---|---|
| フォルダ | − | ○ | − |
| トグル（状態、`persist` が真） | ○ | ○ | ○ |
| トグル（状態、`persist` が偽） | − | ○ | ○ |
| トグル（押下中・実行） | − | ○ | ○ |
| 値（ゲーム、`lockable`） | ○ | ○ | ○ |
| 値（ゲーム、固定できない） | − | ○ | ○ |
| 値（設定） | − | ○ | ○ |
| 実行・画面 | − | ○ | ○ |
| キー（値がホットキーの項目） | − | ○ | − |
| お気に入りのフォルダの行そのもの | （操作が無いので R は何もしない） | | |

言葉は今の状態で変える。

| 操作 | 今の状態 | 言葉 | 印 |
|---|---|---|---|
| 固定（値） | 固定していない / 固定中 | 値を固定 / 固定を外す | 鍵 |
| 固定（トグル） | 固定していない / 固定中 | ONで固定 / 固定を外す | 鍵 |
| お気に入り | 入っていない / 入っている | お気に入りに追加 / お気に入りから外す | 星 |
| ホットキー | 無い | ホットキーを設定（右に近道の Y） | ホットキーの三角 |
| ホットキー | ある | ホットキーを変更（右に近道の Y）、その下に ホットキーを外す | ホットキーの三角 |

ホットキーの有無は編集値（Y で決めた物、適用待ちを含む）で決める。行は最大 4 つ（固定・お気に入り・変更・外す）。

今は使えない操作は灰色で残す（カーソルは置けるが、A で何もしない）。

- ゲームの値が読めない（灰色の行）: 「値を固定」と「ホットキーを設定・変更・外す」が灰色。「固定を外す」と お気に入りはいつでも使える。
- `enabled_if` で無効の行: 同じ。

### 2.2 操作の中身

| 操作 | 起きること | 通知 |
|---|---|---|
| 値を固定 | 編集値を適用値にして 1 回書き、固定する（今の `SetFixed` と同じ）。ホットキーの適用待ちは残す | 題「値を固定」、本文〈名前〉 |
| ONで固定 | 編集値を ON にし、ON を適用して（効果は適用と同じ規則: ホットキーが無ければ効果 ON、あれば待機）固定する。ホットキーの適用待ちは残す | 題「ONで固定」、本文〈名前〉 |
| 固定を外す | 固定だけを外す。値・ON はそのまま（ゲームへ書かない） | 題「固定を外す」、本文〈名前〉 |
| お気に入りに追加 / から外す | お気に入りの並びの最後に足す / 抜く | 題「お気に入りに追加」/「お気に入りから外す」、本文〈名前〉 |
| ホットキーを設定・変更 | リストを閉じ、今の割り当ての枠を出す（Y と同じ。適用待ちになる） | なし（今と同じ） |
| ホットキーを外す | ホットキーを無し（0）にする。適用待ちになる（今の「SELECT 長押し: 無効」と同じ） | なし（適用待ちの点で分かる） |

固定・お気に入りは適用待ちを経ず、その場で効く（旧版の「値を固定」と同じ）。

**通知の言葉の決まり**（この案で足す通知の全て）:

- 項目の名前が入る通知は、**題を操作の言葉（R のリストの言葉と同じ）、本文を項目の名前だけ**にする。「〈名前〉を追加しました」のように名前に助詞をつなげない（「スコップを強くするを追加しました」の「〜するを」が読みにくいため）。
- 本文の名前は今の通知の規則のまま、禁則つきで折り返す（積む件数による空きで 1〜3 行、収まらなければ最後の行を `…` で切る）。名前を途中で `…` に切って 1 行にはしない（名前は省かずに読める方を選ぶ。説明の窓の名前の帯と同じ方針）。
- 名前の入らない通知（件数・結果だけの物）は、本文を **1 行（全角 16 字分、128 画素以内。本文の幅は 130）** に収まる言い方にする。2 行目に 1〜2 字だけ残るような折り返しを作らない。

### 2.3 開閉とボタン

| ボタン | リストを閉じている時（メニューの一覧） | リストを開いている時 |
|---|---|---|
| R | 選んだ行のリストを開く（行が無い・操作が無い時は何もしない） | 閉じる |
| 上下 | − | えらぶ。押した瞬間は端で折り返し、リピートでは端で止まる（一覧と同じ） |
| A | − | 選んだ操作を実行して閉じる。灰色の操作では何もしない（閉じない） |
| B | − | 閉じる |
| Y | ホットキーの割り当て（今のまま） | ホットキーの行があれば、それを実行（リストを閉じて割り当ての枠） |
| X・L・左右・START・SELECT | − | 受け付けない（入力の枠・確認と同じ扱い） |

- リストは確認・入力の枠と同じく「モーダル」に数える（`Shell::Modal()`）。開いている間はメニューの開閉（SELECT）も効かず、ゲームへの入力の遮断も続く。
- 開くと、カーソルは最初の使える操作に置く。前回の位置は覚えない。
- X・L の長押しの途中、確認・入力の枠が出ている時、設定画面では R は効かない。
- 開閉の動きは 160 ms・三次の減速（`ca2.time.actions`）。左（行の側）から 8 画素動きながら現れ、閉じる時は逆。途中で閉じたら今の位相から戻す。A で実行した時も同じ動きで閉じる（実行は押した時に 1 回だけ）。

### 2.4 位置

- 右の列（説明の窓・入力の枠と同じ x 236、幅 160）に出す。題の帯（項目の名前）を選んだ行と同じ高さに置き、窓と窓の間 4 画素に行への指し（左向きの三角）を出す。
- 下の方の行では、窓の下端を 214（操作の帯の上）に収めるために上へずらす。指しは行の高さのまま。窓が上端 4 まで上がっても行が窓の高さの外になる場合は、指しを出さない（10 行・4 操作では起きない）。
- 開いている間は説明の窓を描かない（入力の枠と同じ）。
- 通知は今の規則のまま一番上に描く。前の操作の通知が残っていると、下の方の行で開いたリストの下側に重なる（通知は 2.6 秒で消える）。避けるための並べ替えはしない（11 節の決める事 D）。

### 2.5 下の帯

| 場面 | 案内 |
|---|---|
| メニューの一覧 | A 決定・（左右 値）・B 戻る・X 適用・L 戻し・Y キー・**R 操作**・**START 設定**、右端に n変更 |
| 選んだ行に操作が無い（お気に入りのフォルダの行） | R を出さない |
| R のリスト | 上下 えらぶ・A 決定・B 閉じる（n変更は出さない） |
| 設定画面 | A 決定・（左右 値）・B 戻る・START 閉じる（n変更は出さない） |
| 設定画面の「固定中の項目」の中 | A 外す・B 戻る・START 閉じる |

START の印は新しく作る（23×11、D.12）。値の行で 8 つ並べても、n変更の左に 40 画素ほど残る。

## 3. 固定

### 3.1 対象と意味

| 種類 | 固定できる条件 | 固定の中身 | ゲームが変えた時 | 次の起動 |
|---|---|---|---|---|
| ゲームの値 | `lockable = true` | 固定値（適用値） | 読めて固定値と違う時だけ書き戻す。読めないフレームは何もしない（今の `DriveFixed`） | 読めるようになってから固定値を書く |
| トグル（状態） | `persist = true`（既定） | 項目の ON | ホットキーが無い（効果 ON のはず）のに効果が外れていたら、効果を入れ直す。ホットキーがある（待機）時は効果を触らない（ホットキーが切り替える） | ON にする（ホットキーがあれば待機） |
| そのほか | 固定できない | − | − | − |

- トグルの「ゲームが変えても戻す」は、効果の入れ直し。`Patch.is_active` で外れたと分かった時だけ `Patch.set(true)` を呼ぶ。失敗の通知は固定の間に 1 回だけ出し、以後は毎フレーム黙って試す（失敗の通知が積み重ならないように）。`is_active` を結んでいない項目はエンジンの記録で判断するので、入れ直しは起きない（ゲームが効果を外しうる機能は `is_active` を結ぶ）。
- 固定を外しても、値・ON はそのまま残る。その起動の間は今の状態のままで、次の起動では持ち越さない（トグルは「トグルを全て保持」なら持ち越す）。

### 3.2 編集・適用・戻しとの関係

今のエンジンの値の固定の振る舞いを土台にする。

| 場面 | ゲームの値（固定中） | トグル（固定中） |
|---|---|---|
| 左右・入力の枠で編集 | できる。適用待ちになる | A で ON/OFF の編集ができる。適用待ちになる |
| 適用（X・閉じる時・全適用） | 新しい適用値で固定し続ける（今の `ApplyValue`） | ON の適用は何も変わらない。**OFF を適用したら固定を外す**（通知「〈名前〉の固定を外しました」）。11 節の決める事 A |
| 戻し（L・全戻し） | 編集値を固定値へ戻す | 編集値を ON へ戻す |
| 開いた時の読み直し | 固定値を見せ続ける（今の `ReadGame`） | − |
| 同じ group の別の項目を ON にした | − | 排他で OFF になるので、固定を外す（通知は同じ） |
| 固定する時に適用待ちがある | 値の適用待ちは固定で適用される。ホットキーの適用待ちは残る | 同じ |

### 3.3 印

鍵の印を「外すまでこのまま」の唯一の合図にする（見た目は D.12）。

- 値の行: 今のまま値の左 8 画素。字も固定の色。
- トグルの行: スイッチの左 8 画素（新しい）。スイッチの色・字は今のまま。
- 選択中の行: 鍵を白にして、字と同じ右下 1 画素の影を付ける（今は選択中も青で、緑の帯の上で読みにくい）。
- 選択中で値の左右に ◀ ▶ を出す時: 鍵を ◀ のさらに左（◀ の左 2 画素、値の左 − 13）に置き、名前の省きの右端にもその位置を使う。**今の製品の `panel.cpp` は鍵（値の左 − 8）を ◀（値の左 − 6）の後に描くので、選択中の固定の値の行で ◀ が鍵に重なって隠している。これも直す対象にする**（10 節の順 2）。
- ◀ ▶ を出すのは左右で値が変わる行（数値・スライダー・選択）だけにする。今の製品は、値の欄のある行なら複数選択・キーの項目でも選択中に ◀ ▶ を出す（左右では何も変わらない）。これも直す対象にする。編集できない一覧（設定画面の「固定中の項目」）でも出さない。
- 説明の窓の状態: 値「固定中: 外すまでこの値を保ちます」、トグル「固定中: 外すまでONのままです」（今の「値を固定中」を置き換える）。適用待ちがある間は「適用で反映」を優先する（今の順のまま）。

## 4. お気に入り

### 4.1 一覧の場所と行

- 一番上の一覧の先頭に、仮のフォルダ「お気に入り」を置く。見える項目が 1 件も無い時は行ごと出さない（開発用の項目は製品版では数えない）。
- 行の見た目は普通のフォルダと変える: 星の印・金の淡い地・件数（`4件`）・下の区切りを金の実線（D.12）。CTRPF のお気に入りの見た目はまねない。
- 題の道筋は `GOHAN > お気に入り`。位置 `n/m` は中の件数。

### 4.2 中の一覧

- 並びは**追加した順**（新しい物が最後）。11 節の決める事 B。
- 行は元の項目そのもの。ON/OFF・値・適用待ち・ホットキー・固定は元の場所と共有する。中で編集・適用・R の操作をしても、元の項目に効く。
- 説明の窓に「場所: 〈親の道筋〉」（最上位の項目は「場所: 一番上の一覧」）を状態の下に出す。
- フォルダをお気に入りにした場合、中の一覧ではフォルダの行。A で入ると、道筋は `GOHAN > お気に入り > 村` で、B でお気に入りへ戻る（入口ごとの扱い。元の場所の道筋には移らない）。
- 中の行で R →「お気に入りから外す」: その行が一覧から消え、選択は次の行へ（最後の行なら前の行へ）。帯は今の選択の動き（100 ms）で動く。最後の 1 件を外したら、フォルダの動きで一番上の一覧へ戻り、選択は先頭の行に置く。

### 4.3 位置の保持（D.8 との関係）

- お気に入りの中の位置も、同じ起動中は D.8 と同じ規則で保つ（閉じて開くと同じ行）。
- 再開時の経路の検査では、お気に入りの中の項目を「お気に入りの子」として扱う。外された・隠れた項目は D.8 と同じく次の兄弟へ寄せ、空になったら一番上へ戻る。

## 5. 設定画面（START）

### 5.1 構成

```
設定
├ 固定中の項目  >   n件      （仮のフォルダ。固定中の項目を元の行の見た目で並べる）
├ 保持設定      >
│   ├ トグルを全て保持   [OFF]   （スイッチ）
│   └ 保存を全て消す     [実行]  （確認を出す）
└ 押し切るボタン   [START]     （複数選択。選んだボタンを印で並べる。A で選択の枠）
```

| 行 | 説明（画面の言葉） | 振る舞い |
|---|---|---|
| 固定中の項目 | 固定している項目の一覧です。A で固定を外せます。 | 固定した順に並べる。行は元の項目の見た目（鍵付き）で、編集はできない。左右・X・L・Y・R は効かず、選択中の行にも ◀ ▶ を出さない。A で固定を外す（その場で、通知 題「固定を外す」本文〈名前〉）。行が消え、選択は次の行へ。0 件の時は行を灰色にして入れず、説明の状態に「固定している項目はありません」 |
| 保持設定 | 次回に残す物を決めます。 | フォルダ |
| トグルを全て保持 | ON にすると、ON のトグルを全て次回も ON にします。OFF の間は、固定したトグルだけを次回も ON にします。 | 既定 OFF。切り替えたらその場で効く（適用待ちを経ない） |
| 保存を全て消す | 固定・お気に入り・ホットキー・設定の値・この画面の設定を全て最初に戻し、保存も消します。 | A で確認「保存を全て消しますか？」（消す / キャンセル、既定の選択はキャンセル）。消すを選ぶと 11 節の決める事 H の範囲を既定に戻し、すぐ保存する。通知 題「保存を全て消す」本文「全て最初に戻しました」 |
| 押し切るボタン | 選んだボタンは、押している間ゲームに渡さず、はなした時に 1 回だけ渡します。START+十字上 などのホットキーでゲームが動かないようにします。 | 選択肢 A・B・X・Y・START、既定は START だけ。行の値は「1/5」の数でなく、**選んだボタンをボタンの印で並べる**（A と START なら A の印と START の印。1 つも無ければ「なし」）。左右では変わらないので ◀ ▶ を出さない。A で複数選択の枠（A 切替・X 決定・B 取消）を出し、枠の選択肢もボタンの印で並べる（D.12.4。**今の製品の枠の「[ ] A」の文字の箇条を、箱と ✓ の見た目に変える**）。決定でその場で効き、入力の遮断の所有者 `settings` の `defer` を置き換える（[入力の遮断](input-block.md) 5.5） |

- ボタンの印で見せる複数選択は spec で `display = "buttons"` と書く（選択肢の名前がボタンの名前 A・B・X・Y・L・R・START などであることを codegen が検査する）。ほかの複数選択は今の「n/m」のまま。
- 設定画面の行は R のリスト・固定・お気に入り・ホットキーの対象にしない。適用待ちも無い（変えたらその場で効き、覚える）。
- 押し切るボタンの選択肢は旧版と同じ 5 つ。L・R・十字は、ホットキーの組み合わせの先頭に使うことが多く、押し切るとゲームでの普段の操作が遅れるので入れない（11 節の決める事 E）。

### 5.2 開閉とボタン

| ボタン | 設定画面 |
|---|---|
| START | メニューの一覧で押すと開く。設定画面のどこで押しても閉じて、メニューの一覧の元の位置へ戻る |
| B | 1 段戻る。設定画面の一番上で押すと閉じる（メニューの一覧へ戻る。メニュー自体は閉じない） |
| A | 決定（フォルダに入る・スイッチを切り替える・選択の枠・実行）。固定中の項目の中では「外す」 |
| 左右 | 値の行（今は無い）だけ |
| X・L・Y・R | 受け付けない |
| SELECT | メニューごと閉じる。次に開いた時はメニューの一覧の元の位置（設定画面には戻らない。11 節の決める事 F） |

- 確認・入力の枠・R のリストが出ている間、X・L の長押しの途中は START は効かない。メニューを閉じている時の START は今のままゲームへ渡る（押し切りの対象なら離した時に 1 回）。
- 開閉の動きはフォルダの出入りの動き（`ca2.time.folder`、200 ms・32 画素）。開く時はメニューの一覧が左へ、設定画面が右から入る。道筋の先頭は「設定」に替わる（`設定 > 固定中の項目`）。
- 同じ起動中は、設定画面の中の位置も D.8 と同じ規則で保つ。

## 6. 持ち越し

### 6.1 何を持ち越すか

| 物 | 持ち越す | 条件・注意 | spec |
|---|---|---|---|
| 設定の値（数値・選択・複数選択・スライダー、`source = "setting"`）とキーの項目 | いつも | 適用値だけ（適用待ちは持ち越さない） | `persist`（既定 真）。偽なら持ち越さない |
| ホットキー | いつも | 適用済みで、既定と違う物だけ | （項目の種類によらない） |
| お気に入り | いつも | 並びも | − |
| 固定したゲームの値 | いつも | 固定値 | `lockable` |
| 固定したトグル（状態） | いつも | ON | `persist`（既定 真）。偽なら固定できない |
| 固定していないトグル（状態） | 「トグルを全て保持」が ON の時だけ | ON の物だけ。持ち越した物は固定にはならない | `persist`（既定 真） |
| メニューの設定（トグルを全て保持・押し切るボタン） | いつも | − | 設定画面の項目 |
| 押下中・実行のトグル、実行、画面 | 持ち越さない | ホットキーとお気に入りは持ち越す | `persist` は偽だけ（真は誤り） |
| 固定していないゲームの値 | 持ち越さない | 次の起動で勝手に戻らないように | `persist` は偽だけ（真は誤り） |
| 開いていたフォルダ・選択・スクロール | 持ち越さない | D.8 のとおりメモリだけ | − |

### 6.2 spec の `persist` の変更

今の codegen は `persist` の既定を「画面（mode）とゲームの値以外は真」にしている。次のように変える。

| 種類 | 既定 | 真にできるか | 真の意味 |
|---|---|---|---|
| 値（設定）・キー | 真 | できる | 適用値を覚える |
| トグル（状態） | 真 | できる | 固定でき、「トグルを全て保持」の対象 |
| トグル（押下中・実行）・実行（trigger） | **偽（変更）** | **できない（変更）** | − |
| 画面（mode） | 偽 | できない（今のまま） | − |
| 値（ゲーム） | 偽 | **できない（変更。固定は `lockable`）** | − |

`docs/menu.md` の備考の「保持しない」は、固定の言葉に合わせて「持ち越さない」にする（状態のトグルで偽の時は「固定できない」）。

## 7. 保存

### 7.1 置き場所

同梱の CTRPF の設定ファイル（`GohanCTRPFData.bin`）の gohan の欄（`GohanData` の `SetHandlers`・`Load`・`Save`）。ファイルの見出しの予約語が欄の場所と版（1）を持つので、gohan の欄の中身は gohan が決める。旧版の欄（先頭が `GMP1`）は読まずに既定で始める（移し替えはしない。旧版と同じ方針）。

### 7.2 形式（リトルエンディアン）

```
'GHN3'                  先頭の印（4 バイト）
u16 版 = 1
u8  メニューの設定の旗  bit0 トグルを全て保持
u8  予備 = 0
u16 押し切るボタン      key のビット（A・B・X・Y・START の部分集合）
u16 項目の記録の数
{ 項目の記録 } ...
```

項目の記録（1 項目につき 1 つ。覚える物が無い項目は書かない）:

```
u8  id の長さ（1〜64）
    id（spec の id。ASCII）
u8  欄の旗  bit0 値 / bit1 ホットキー / bit2 固定 / bit3 ON / bit4 お気に入り
[s32 値]            bit0: 設定の値の適用値、または固定したゲームの値の固定値
[u16 ホットキー]    bit1: 適用済みのホットキー（既定と違う時だけ）
[u16 並び]          bit4: お気に入りの並び（0 から）
```

固定の並び（設定画面の「固定中の項目」の順）は bit2 の記録の順で表す。

- **鍵は spec の id**（旧版はラベルの階層パス）。ラベルの言葉を直しても保存が外れない。id は spec で一意で、階層と無関係。id を変えた項目の保存は外れる（旧い id を書く仕組みは作らない）。
- 大きさの上限は codegen が spec から計算する（全項目の id の長さ＋欄の最大）。今の上限の 192 項目・id 64 字でも 1 項目 74 バイト以下なので、新しく足す定数 `core::limits::PersistBytes`（16384。今の `src/core/limits.hpp` には無い）に収まることを静的に検査する。
- 読む時の検査: 印・版・長さ・範囲。未知の id・種類の合わない欄・範囲外の値は、その欄だけ捨てる（他は読む）。値は `SetValue` と同じく範囲に収める。ホットキーは予約（SELECT）を含む物・他の項目と重なる物を捨てる（既定のまま）。全体が壊れていたら全て既定で始める。

### 7.3 いつ保存するか

| 時 | 中身 |
|---|---|
| メニューを閉じ切った時（閉じる動きの後、確認・入力の枠も無い） | 覚える物が前回の保存から変わっていれば保存を頼む |
| メニューを閉じたままの変化（ホットキーの入力の枠での決定など）の後、メニュー・モーダルが無くなった時 | 同上 |
| 保存を全て消す | すぐ頼む |
| CTRPF のメニューを閉じた時 | CTRPF が自分の保存のついでに gohan の欄も書く（書き手は最新の写しを渡す） |
| プラグインの終了時 | 書かない（ファイルの読み書きを終了の途中にしない。変化はメニューを閉じた時に保存済み） |

- エンジンは覚える物が変わるたびに版の数を 1 増やす（固定・お気に入り・適用済みのホットキー・覚える設定の値・覚えるトグルの ON・メニューの設定）。閉じ切った時に、前回保存した版と違えば写しを作る。
- 写しはゲームのスレッドで作り、`core::Mailbox` で渡す（16 KiB の固定長。競合したら次のフレームで再送）。
- ファイルの書き込みはゲームのスレッドでしない。CTRPF の `Task` で作業のスレッドを 1 本持ち、`GohanData::Save()` を呼ぶ。書き手のコールバックは Mailbox から最新の写しを写す（Busy なら 1 ms 待って再試行。作業のスレッドなので待ってよい）。保存の途中に次の頼みが来たら、終わった後にもう 1 回だけ書く。
- 失敗は状態表示（開発版）に残し、通知は出さない（次に閉じた時に再び試す）。

### 7.4 読み込み

プラグインの初期化で `menu_screen` の `Wire` が、毎フレームの処理を登録する前に `GohanData::SetHandlers` と `Load` を呼ぶ（プラグインのスレッドなのでファイルを読んでよい）。読み手のコールバックは `Load` の中で同じスレッドから呼ばれるので、その中で `menu::persist` の読み込み（純粋な関数）をエンジンに当てる（欄を写す領域は要らない）。エンジンをゲームのスレッドが触り始めるのはその後なので、受け渡しの排他は要らない。

## 8. 起動時の戻し

| 物 | 戻し方 | いつ |
|---|---|---|
| メニューの設定 | 旗と押し切るボタンを入れる。押し切るボタンは所有者 `settings` の要求に置く | 読み込みの時 |
| 設定の値 | 編集値と適用値に入れ、`SettingValue.applied` を呼ぶ | 読み込みの時 |
| ホットキー | 編集値と適用値に入れる | 読み込みの時 |
| お気に入り | 並びを入れる | 読み込みの時 |
| 固定したゲームの値 | 固定と固定値を入れる。書くのは今の `DriveFixed`（読めて違う時だけ） | ゲームから読めた最初のフレーム（その時に「戻した」に数える） |
| ON のトグル（固定・トグルを全て保持） | 編集値と適用値を ON にする。ホットキーがあれば待機で終わり。無ければ効果を入れる | 効果は毎フレーム `Patch.set(true)` を試し、`NotReady` の間は黙って待つ。`Ok` で「戻した」、それ以外の失敗で「戻せない」に数える |

- 戻しを待っている物が全て片付いたら、通知を 1 つ出す。題「前回から」、本文「n 件を戻しました」（n は戻した固定の値とトグルの数）。戻せない物があれば赤で「n 件を戻し、m 件は失敗」（n・m が 3 桁でも 1 行に収まる）。数える物が 0 件なら出さない。設定の値・ホットキー・お気に入りは数えない（ゲームに触れないので、その場で戻る）。
- ゲームの値が長く読めない（タイトル画面にいる）間は、通知も待つ。メニューを先に開いても、固定した値は鍵付きで固定値を見せる（今の `ReadGame`）。
- 効果の通知（「〈名前〉を有効にしました」）は戻しでは出さない（結び付けただけでは通知しない、今の方針と同じ）。

## 9. エンジン・描画の変え方の要点

- **項目の表**: 設定画面の項目を `spec/menu.toml` の `[[settings]]` に書き、同じ表の後ろに生成する（`MenuId` に入る、根は `kSettingsRoot`）。新しい鍵: `list = "fixed"`（仮のフォルダの中身）、`apply = "immediate"`（適用待ちを経ない）、確認 `confirm = "menu"`（メニューで実行する時も確認）。トグルに `behavior = "value"`・`source = "setting"` を許す（設定の真偽値。効果・通知・ホットキーを持たない）。
- **仮のフォルダ**: お気に入りと固定中の項目は、子の並びをエンジンが持つフォルダにする。`FirstVisible`・`NextVisible`・`RestorePosition` の親子の判定を、仮のフォルダの並びでも働くように「子の並び」を返す関数に寄せる。Panel は同じ関数で行を集める。
- **固定**: `ItemState.fixed` をトグル（状態）にも使う。`SetFixed` をトグルに広げ（3.1・3.2）、`DriveFixed` にトグルの効果の入れ直しを足す。OFF の適用・排他で固定を外す。
- **R**: `PressMenu` の R で `UiRequest{UiKind::Actions, 項目}` を出す。並べる操作は `Engine::Actions(item, out)`（純粋な関数で、2.1 の表と灰色を返す）、実行は `Engine::RunAction(item, kind)`。リストの入力・描画・動きは `Entry` と同じ形のクラスで Shell が持つ。
- **START**: `PressMenu` の START で設定画面の根へ移る（スタックの底を `kSettingsRoot` に替える）。フォルダの動きはそのまま使う。
- **版の数**: 覚える物が変わるたびに増やす（7.3）。
- **メモリ（プラグイン側）**: お気に入りの並び u16 × 192 = 384 バイト、固定の並び 384 バイト、版の数と操作のリストの状態（数十バイト）。保存の写しの組み立て用 16,384 バイトと Mailbox 16,384 バイト（計 32,768 バイト。ゲームのスレッドの小さなスタックに置かない）を静的領域に置く（ゲームのヒープは使わない。静的区分の 2 MiB 未満の検査に含める）。CTRPF の書き込みの `std::vector`（最大 16 KiB）は保存の時だけ作業のスレッドでプラグインのヒープから借りる。描画資源（ゲームの描画用ヒープ）の常駐量は変わらない（D.12.7）。
- **層**: 直列化・読み込み・起動時の戻しの判定は `src/menu/persist.{hpp,cpp}`（CTRPF に依存しない純粋な関数、PC 試験）。`GohanData` と `Task` は `src/features/menu_screen/`（状態表示の書き出しと同じく features が CTRPF のファイルを使う）。

| F | 設定画面のまま SELECT でメニューを閉じ、次に開いた時 | (1) メニューの一覧の元の位置／(2) 設定画面の中の位置 | (1)。設定画面は寄り道として扱う |
| G | 押下中・実行のトグルの ON を「トグルを全て保持」に含めるか | (1) 含めない（押している間だけ動く物は持ち越さない、の決定どおり）／(2) 含める | (1) |
| H | 保存を全て消す時に戻す範囲 | (1) 固定・お気に入り・ホットキー・設定の値・設定画面の設定の全部／(2) 固定・お気に入りだけ | (1)。「保存した状態を全部消す」の言葉どおり。今 ON のトグルの効果はその起動の間は残る |
| I | 起動時の通知を出す時 | (1) 待っている物が全て片付いた時に 1 つ／(2) 最初に何か戻した時に 1 つ（後から戻った物は数えない） | (1)。件数が正しい。ゲームの値が読めるまで遅れる |
| J | 複数選択の枠の見た目の変え方 | (1) 全ての複数選択の枠を「箱と ✓」にし、ボタンの選択肢だけ字の代わりに印を並べる／(2) ボタンの選択肢の枠だけ変え、ほかは今の「[ ] 字」のまま | (1)。枠の見た目がそろう。今ある複数選択はこの行だけなので、変える物は少ない |

## 12. 旧版との違い

| 旧版 | この案 |
|---|---|
| R でお気に入りを直接切り替え | R で操作のリスト（お気に入り・固定・ホットキー） |
| START の設定画面に項目ごとの操作（この項目を保持・値を固定・お気に入り） | 項目ごとの操作は R のリストへ。設定画面はメニュー全体の設定だけ |
| 「この項目を保持」と「値を固定」 | 「固定」1 つ |
| 項目の保持設定（値の固定・トグル状態 × 保持された項目・お気に入り・全項目） | 「トグルを全て保持」だけ |
| お気に入りを保持（設定） | いつも覚える |
| お気に入りとトグルの持ち越しの連動 | 無し |
| 行の左端の縦線（お気に入り・保持・ホットキー） | ホットキーは今の三角、固定は鍵、お気に入りは印無し（決める事 C） |
| 鍵はラベルの階層パス、版 2 | 鍵は spec の id、新しい形式（旧版の欄は読まない） |
| 固定していないゲームの値は持ち越さない・ホットキーは常に持ち越す（2026-09 の決定） | そのまま引き継ぐ |

# メニューの一覧

`spec/menu.toml` から `tools/gohan_tools/codegen/menu.py` が作った一覧です。手で編集しないでください。

- 振る舞い: 状態＝効果が続く / 押下中＝押している間だけ動く / 実行＝1 回実行 / 画面＝開いて閉じる / 値＝値を反映する
- 値の出どころ: 設定＝gohan の変数 / ゲーム＝開いた時にゲームから 1 回読む
- 開発用は開発版（`make DEV=1`）だけに出ます。

| 項目 | ID | 見た目 | 振る舞い | 出どころ | 既定 | ホットキー | 備考 | 説明 |
|---|---|---|---|---|---|---|---|---|
| 見本 | `sample` | フォルダ | - | - | - | - | - | メニューの枠組みを確かめるための見本です。ゲームには触れません。 |
| 　見本の旗 | `sample.flag` | トグル | 状態 | - | OFF | L+Up | - | 旗を立てます。ホットキーがあれば、ホットキーで立てる・下ろす。 |
| 　見本の押下中 | `sample.hold` | トグル | 押下中 | - | OFF | R+A | - | ホットキーを押している間だけ数を数えます。 |
| 　見本のスタンプ | `sample.stamp` | 実行 | 実行 | - | - | L+Down | 適用で実行、ホットキーで確認 | 押すと 1 回だけ数を増やします。メニューでは適用で実行します。 |
| 　見本の画面 A | `sample.editor_a` | 実行 | 画面 | - | - | - | 排他: editor、保持しない | 画面を開きます。もう一度で閉じます。 |
| 　見本の画面 B | `sample.editor_b` | 実行 | 画面 | - | - | - | 排他: editor、保持しない | A と同時には開けません。後から開いた方が前の方を閉じます。 |
| 　見本の値 | `sample.values` | フォルダ | - | - | - | - | - | 値の出どころが 2 通りあることを示します。 |
| 　　見本の方法 | `sample.mode` | 選択 | 値 | 設定 | 自由 | - | - | 移動量の有効・無効を切り替えます。 |
| 　　見本の量 | `sample.amount` | 数値 | 値 | 設定 | 5.0 | - | 有効条件: sample.mode != 'マス単位'、範囲 0.1..99.9 | 自由な動きの量です。 |
| 　　見本の所持金 | `sample.wallet` | 数値 | 値 | ゲーム | 0 | - | 値の固定可、保持しない、範囲 0..99999 | 見本の値です。ゲームの値の代わりに見本の変数を読み書きします。 |
| 　　見本の開発用 | `sample.dev_note` | トグル | 状態 | - | OFF | - | 開発用 | - |

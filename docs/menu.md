# メニューの一覧

`spec/menu.toml` から `tools/gohan_tools/codegen/menu.py` が作った一覧です。手で編集しないでください。

- 振る舞い: 状態＝効果が続く / 押下中＝押している間だけ動く / 実行＝1 回実行 / 画面＝開いて閉じる / 値＝値を反映する
- 値の出どころ: 設定＝gohan の変数 / ゲーム＝開いた時にゲームから 1 回読む
- 開発用は開発版（`make DEV=1`）だけに出ます。

| 項目 | ID | 見た目 | 振る舞い | 出どころ | 既定 | ホットキー | 備考 | 説明 |
|---|---|---|---|---|---|---|---|---|
| 見本 | `sample` | フォルダ | - | - | - | - | - | メニューの枠組みを確かめるための見本です。ゲームには関わりません。 |
| 　見本のフラグ | `sample.flag` | トグル | 状態 | - | OFF | L+Up | - | フラグを立てます。ホットキーがあれば、ホットキーで立てる・下ろす。 |
| 　見本の押下中 | `sample.hold` | トグル | 押下中 | - | OFF | R+A | - | ホットキーを押している間だけ数を数えます。 |
| 　見本のスタンプ | `sample.stamp` | 実行 | 実行 | - | - | L+Down | 適用で実行、ホットキーで確認、持ち越さない | 押すと 1 回だけ数を増やします。メニューでは適用で実行します。 |
| 　見本の画面 A | `sample.editor_a` | 実行 | 画面 | - | - | - | 排他: editor、持ち越さない | 画面を開きます。もう一度で閉じます。 |
| 　見本の画面 B | `sample.editor_b` | 実行 | 画面 | - | - | - | 排他: editor、持ち越さない | A と同時には開けません。後から開いた方が前の方を閉じます。 |
| 　見本の値 | `sample.values` | フォルダ | - | - | - | - | - | 値の出どころが 2 通りあることを示します。 |
| 　　見本の方法 | `sample.mode` | 選択 | 値 | 設定 | 自由 | - | - | 移動量の有効・無効を切り替えます。 |
| 　　見本の量 | `sample.amount` | 数値 | 値 | 設定 | 5.0 | - | 有効条件: sample.mode != 'マス単位'、範囲 0.1..99.9 | 自由な動きの量です。 |
| 　　見本の所持金 | `sample.wallet` | 数値 | 値 | ゲーム | 0 | - | 値の固定可、持ち越さない、範囲 0..99999 | 見本の値です。ゲームの値のかわりに見本の変数を読み書きします。 |
| 　　見本のテスト用 | `sample.dev_note` | トグル | 状態 | - | OFF | - | 開発用 | - |
| 設定 | `settings` | フォルダ | - | - | - | - | - | メニュー全体の設定です。次の起動に残す物と、押し切るボタンを決めます。 |
| 　固定中の項目 | `settings.fixed` | フォルダ | - | - | - | - | 中身は固定中の項目 | 固定している項目の一覧です。A で固定を外せます。 |
| 　保持設定 | `settings.keep` | フォルダ | - | - | - | - | - | 次の起動に残す物を決めます。 |
| 　　トグルを全て保持 | `settings.keep.toggles` | トグル | 値 | 設定 | OFF | - | 適用待ちなし | ON にすると、ON のトグルを全て次の起動でも ON にします。押している間だけ動く物も入り、1 回だけ動く物は入りません。OFF の間は、固定したトグルだけを戻します。 |
| 　　保存を全て消す | `settings.keep.erase` | 実行 | 実行 | - | - | - | メニューで確認、持ち越さない | 固定・お気に入り・ホットキー・設定の値・この画面の設定を全て最初に戻し、保存も消します。 |
| 　押し切るボタン | `settings.press_through` | 複数選択 | 値 | 設定 | Start | - | 適用待ちなし、ボタンの印で表示 | 選んだボタンは、押している間ゲームに渡さず、はなした時に 1 回だけ渡します。START+十字上 などのホットキーでゲームが動かないようにします。 |

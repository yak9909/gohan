サブフォルダは一番上に配置してください。rootはフォルダではありません。
各チートは、一つ一つ解析して実装します。未解析のチートは実装しません。

# root

チャットコマンド
- トグル式
- Default Hotkey: R+B
- Desc: チャットにコマンドを打つ事で様々なチートを素早く実行できます。コマンドリストは list で確認できます。

# root/Player

座標移動
- トグル式
- Default Hotkey: A
- Desc: 移動キーで高速移動できます。
- ホットキーを押しながら移動キーで指定されたキーを押すとその方向へ移動する。
- スライドパッドとCスティックの場合は可能なら8方向ではなくスライドパッドの向きに合わせて移動、傾き度合いに合わせて移動量を調節できるように。
- AnimalBytesから移植

座標移動 -> 移動キー
- リストボックス式項目
- 十字キー, スライドパッド, Cスティック
- デフォルト値: 十字キー
- Desc: 座標移動に使うキーを指定できます。

座標移動 -> 移動量
- 数値入力 float
- デフォルト値: 2.0
- Desc: 座標移動の移動量を設定できます。

座標移動 -> 移動方法
- リストボックス
- 通常, グリッド単位
- デフォルト値: 通常
- Desc: 座標移動の移動方法を変更できます。グリッド単位の時、スライドパッドによる向きは8方向に限定されます。

- Desc: 地図をタッチした場所にワープします。

# チャットコマンド

list
- チャットコマンドを下画面リストボックスで全て表示する。選択すると確定している文字のみチャット欄に入力する。

time set [[[yyyy-]MM-]dd|[HH:]mm|day|night|noon|midnight]
- setだけの場合、時刻設定メニューを呼び出す
 - Foxxyから移植
- HH:MMは24-hour clock式
- 時刻や日にちの直接指定は先頭ゼロ省略可
- day=7:00, night=18:00, noon=12:00, midnight=0:00

time <add|sub> [[[yyyy:]MM:]dd|[HH:]mm]
- 時刻や日にちの直接指定は先頭ゼロ省略可

<ITEMID>
- 存在するアイテムであれば、持ち物の空いたスロットに入れる。テキストにはアイテム名と入ったスロットのindexを表示する。
- [ポケットアイテム] と同じメソッドを使います。

<ITEMNAME>
- 日本語でアイテムを検索する(部分一致)。一致したアイテム候補を下画面リストボックスとして表示する。選択したアイテムを持ち物の空いたスロットに入れる。
- [ポケットアイテム] と同じメソッドを使います。

weather <clear|rain|cloudy>
- [天気] と同じメソッドを使います。

<hair|style|eye[s]>
- メニューを開き [root/Player/PlayerStyles] フォルダを開きます
- チャットは初期化する
